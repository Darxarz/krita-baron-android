# Krita Baron Edition 0.1.10

Includes the Interface settings and desktop/public fonts described in RELEASE_019.md.
This follow-up preserves the selected canvas preview during image capture and price
checks: the preview is temporarily hidden while reading the source, then restored.
Captured source images exclude the preview; the first-click/second-click state stays
consistent. Krita's scope guard also restores visibility on early returns.

New region prompt editors use the configured prompt line count immediately. Custom
tag datasets also accept an uppercase CSV extension on Android's case-sensitive
filesystem. The Android signing identity and Python-free build remain unchanged.

Desktop Qt/package validation is separate from testing on the Samsung tablet.
