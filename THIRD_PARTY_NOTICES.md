# Attribution and sources

Krita AI Diffusion is created and maintained by **Acly and contributors**:
https://github.com/Acly/krita-ai-diffusion

The native Android interface reconstructs that project's UI and behaviour. The
server compiler uses its workflow engine, preserved under `server/vendor/ai_diffusion`.
Original icons, sampler/control presets, translations and document history format
come from the same project. The original project's GNU GPL v3 license is preserved
in `LICENSE`. Existing upstream source notices and authorship are not replaced.

**Darxarz / Baron Edition** identifies the native Android port and modifications:
Orchestrion integration, model galleries, public font integration and the Baron
update channel. This is an independent modified edition; it is not maintained or
endorsed by Acly or the Krita development team. The native source and modified
Krita source are distributed alongside released APKs on the update site.

Krita itself is developed by the **Krita development team and contributors**.
The full source release retains Krita's original source and author/license files.
Its application package and branding are identified as Krita Baron Edition.
