HistoryWidget/GenerationWidget and `ui/widget.py` StrengthWidget. This pass

Changes:

- Remove the extra QFormLayout contents margins around generation fields.
- Put Generate and its mode arrow inside one zero-spacing group, preserving
  the separate gap before the queue button; align arrow/queue heights with
  the Python generation button.
- Set the strength slider keyboard step to five, matching StrengthWidget.

  on history Apply/context overlays; update them when the Krita palette changes.

  aspect ratio and alpha. Pad short landscape thumbnails for the action overlay

  bitmap. Rebuild thumbnails when the user's thumbnail size changes.
