# Сверка Python-плагина и Android 0.1.12

Эталон: текущий локальный Python-плагин `1.53.0-baron.8`, а не скриншоты ранних
релизов. Сравнивались исходники `ui/generation.py`, `ui/control.py`, `ui/region.py`,
`ui/widget.py`, `ui/settings.py`, `model/model.py`, `model/control.py`, `persistence.py`,
`backend/resources.py`, `presets/control.json` и соответствующие нативные классы.

**Полного соответствия всех функций пока нет.** Таблица отделяет перенесённые
механизмы от частичных и отсутствующих. Совпадение исходников и автоматические
проверки не означают проверку на физическом Samsung Galaxy Tab S8+.

## Проверки релиза

Qt-тесты проверяют жесты результатов, вызовы CanvasHost, состояние ControlNet,
интервальный ползунок, сохранение настроек, очередь, сетевые события и историю.
Windows и Linux/AddressSanitizer запускаются отдельно. Проверка обмена аннотациями
использует настоящую Python-модель сохранения, а не только самостоятельно созданный JSON.
Компилятор проверен на 13 тестах и 19 параметризованных сценариях; изменённые Python
файлы проходят Ruff check/format и Pyright. Нативный KisImage host дополнительно
компилируется в полной Android-сборке Krita.

Финальные Qt-прогоны: Windows 58 passed / 0 failed / 1 skipped; Linux ASAN
58 passed / 0 failed / 1 skipped. Пропущена только необязательная внешняя загрузка
Civitai, её адрес для этой задачи не задавался. Для Linux установлен отсутствовавший
Qt WebP decoder; наличие его Android-версии дополнительно проверено внутри APK.
Аннотации из обоих прогонов успешно загрузились в настоящий Python ModelSync.
Серверный compiler обновлён атомарно после сверки 430 неизменённых vendor-файлов;
резервная копия — `Z:/orchestrator/baron-parity-delivery-20261003`.
Перезапуск сайта для compiler-процесса, запускаемого на каждый запрос, не требуется.

Следующий приоритет полного переноса: selection/inpaint context и feather →
backend-aware ControlNet availability и vector pose → множественное выделение
истории/горячие клавиши → точная региональная композиция → остальные workspaces.
APK-проверка подписи, содержимого и совпадения с финальным модулем отделена от
физической проверки на планшете. Этот отчёт не утверждает 100% или pixel-perfect parity.
