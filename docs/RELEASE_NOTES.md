Первая тестовая сборка Krita AI Diffusion — Baron Edition для Android.

Нативная панель C++/Qt, без Python внутри APK:

- раскрывающиеся настройки и оформление по текущей теме Krita;
- полноэкранная галерея моделей и LoRA, поиск и постепенная загрузка картинок;
- вход в Оркестрион через браузер, цены только в беелетиках;
- генерация, редактирование с референсами и выделением, апскейл,
  отделение персонажа с редактируемой маской;
- добавление результата в новый слой и повторное получение готового задания.

Для Android 7+ на ARM64. Отдельное имя приложения: Krita Baron Edition.
Основа — Krita 5.4.0-prealpha. Debug-подпись проверена; Python-интерпретатора
и PyKrita в пакете нет.

Запуск на настоящем планшете, вход через браузер на Android и генерация через
рабочий сайт ещё не проверены. Native API нужно интегрировать в сайт из
подготовленной отдельной ветки. Рабочая сборка сайта не изменена.
Live, Animation и Custom Graph пока не перенесены.

Открой Settings → Dockers → AI Diffusion · Baron Edition.
Подробности проверки и SHA-256 находятся в docs/STATUS.md и apk-verification.json.
