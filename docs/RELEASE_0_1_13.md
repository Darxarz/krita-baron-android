# Android 0.1.13: авторство и исходные подключения

Оригинал: Acly / Krita AI Diffusion. Darxarz / Baron Edition: нативный порт и
модификации. В разделе плагина сохранены имя Acly, Website, Handbook, GitHub,
Issues, Discussions, Discord и видео оригинального проекта. Исходники сохраняют
лицензии, авторство, иконки, переводы и пресеты оригинала. См. THIRD_PARTY_NOTICES.md.

## Подключения

Настройки повторяют исходные карточки Online Service, Local Managed Server и
Custom Server. Orchestrion — отдельная дополнительная карточка. Локальный
управляемый сервер недоступен на Android, как оговорено при начале порта.

- Interstice: оригинальный вход через браузер, аккаунт, каталог ресурсов,
  Generate / Status / Cancel, загрузка исходных изображений через подписанный URL,
  несколько PNG/WebP результатов. Его баланс показывается в image tokens;
  беелетики относятся только к Orchestrion. Цена Interstice пока не перенесена.
- ComfyUI: адрес с необязательным http://, префикс пути и query-токен; необязательный
  Bearer-токен. Каталог и подготовка запроса — через новый серверный модуль;
  дальнейшие prompt / ws / history / view / queue — напрямую через ComfyUI.
- Orchestrion: сохраняет существующий браузерный вход и цену в беелетиках.
- Сохранённые входы разделены по сервису и адресу; выход из одного аккаунта
  не удаляет остальные. На Android секреты сохраняются через Keystore.
- Задания очереди получают копию подключения, поэтому смена сервиса не
  перенаправляет уже отправленные задания на другой сервер.

## Границы соответствия

Это очередной этап переноса, **ещё не полное соответствие 1:1**. Остаток аудита
0.1.12 остаётся в силе: Live, Animation, Custom Graph, векторный OpenPose,
полный inpaint context / grow / feather / blend и часть расширенных параметров.

Interstice пока не проверен реальным аккаунтом и платной генерацией. Нативный
сериализатор поддерживает обычные generate/refine/inpaint запросы, референсы,
регионы и LoRA из облачного каталога; загрузка пользовательских LoRA, оригинальная
оценка стоимости и все специальные варианты workflow пока не перенесены.
Фоновое отделение для Interstice явно отклоняется, а не подменяется генерацией.

Прямой ComfyUI требует `server/comfyui-baron-native`; чистый ComfyUI пока не
предоставляет маршруты нативной подготовки. Они не запускают генерацию.

## Проверка

Результаты записываются в `artifacts/` и `build/tests-connections-*`.
На настоящем сервере 192.168.50.191:8188 проверены каталог (601 запись) и сборка
generate/edit запросов для Qwen 2.1 и Krea 2. Инференс не запускался, очередь до
и после проверки пустая. Продукционный компилятор Orchestrion не изменён.

Нативный WorkflowInput читается и повторно сохраняется настоящим API Python-
плагина: проверены изображения с альфой, маски, регионы, LoRA, сила и сид.
История документов также проверяется настоящим Python ModelSync.
Тесты используют Qt с проверкой обращений к памяти, тестовый HTTP-транспорт и
настоящий отдельный процесс компилятора. Это не проверка запуска на Samsung.
